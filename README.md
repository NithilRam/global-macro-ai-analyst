# LLM-Powered Geopolitical Risk & Financial Market Analysis Tool

This project is a Python-based application that utilizes a large language model (LLM)
to monitor how geopolitical scenarios can affect financial markets.

The tool generates investment-style memos analyzing how geopolitical events
impact equities, fixed income, and foreign exchange markets across the United
States and the Eurozone.

## Key Features
- User-defined geopolitical risk inputs
- Structured global macro and market transmission framework
- Asset-class level financial analysis (Equities, Fixed Income, FX)
- Programmatic LLM integration via API
